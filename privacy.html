一、信息处理及用途

信息与场景用途、去向和选择
荣耀账号登录荣耀提供账号登录与关联服务。本游戏应用层只使用登录返回的 OpenID 识别本次登录，并由其生成稳定的角色标识；该标识仍与您的账号相关，不等于匿名信息。本次登录状态及角色标识在应用运行期间使用，退出进程后不由我们的应用层保存。我们不读取或保存 SDK 返回的账号头像、账号昵称、手机号、UnionID 或登录令牌；SDK 自身的处理见第二部分。
游戏昵称与角色信息昵称可不填写，默认角色名为“毛线玩家”。您填写的昵称会在本机保存，并与角色标识、当前普通模式关卡等级、关卡章节、游戏积分及本机关卡区服信息一同通过 SDK 上报荣耀，用于角色关联、游戏服务及防沉迷等联运管理。首次进入菜单、进度保存和修改昵称时可能更新上报。请勿填写真实姓名、身份证号、手机号等敏感内容。
本地游戏存档关卡、道具、收集状态、积分和音乐音效、振动设置保存在应用私有区域，以便继续游戏。当前没有云存档或跨设备恢复；角色上报并非完整存档备份，我们未把全部关卡数据或道具存档上传到自己的服务器。
同意记录应用在本机记录您是否同意本版政策。旧本地游客版的同意记录不能直接用于新增联运服务；本版会重新提示。拒绝时不初始化账号联运服务或游戏引擎。明确同意后，只有您主动选择账号登录时才开始联运登录流程。
实名认证与防沉迷需要实名认证时，您向荣耀服务提供姓名、身份证号码等敏感个人信息；我们不另设身份证录入框，也不接收或保存这些身份材料。荣耀依其服务规则处理实名与防沉迷，应用按其结果及退出通知控制进入、继续或结束游戏。相关功能取决于账号状态、荣耀服务及平台配置。
主动咨询您通过邮件、电话向我们提交的联系方式、问题描述和必要附件，仅用于回复、核实和处理请求；请勿提交无关个人信息。

我们没有另建游戏账号或登录令牌验证服务器，不提供云存档、聊天或在线排行榜。游戏主逻辑在本机运行，但账号登录和荣耀服务需要网络；登录结果由客户端接收，不能理解为我们已另行完成服务端身份核验。

四、存储期限与安全

本机昵称、存档、设置和同意记录保存在应用私有区域，应用关闭自动备份。除角色上报外，我们没有提供游戏账号后台或云端存储。本次账号与角色标识仅在应用运行期间使用，不由我们的应用层跨进程保存；荣耀 SDK 的缓存和服务端记录按其规则管理。

荣耀声明其中国大陆服务的数据保存在中国大陆服务器。按对应声明，登录类记录保留至相关账号删除，实名资料通常保留1年，安全运行等记录通常保留3年；分析上传记录通常保留1年，端侧临时信息不留存。具体类型、期限及例外以链接中的荣耀声明及适用法律为准，不代表本机删除会同步删除这些平台记录。

咨询资料只在处理问题和履行法定义务所需期间保留，完成目的后依法删除或去标识化。我们使用应用私有存储、减少附加资料请求、限制本次登录状态保存等措施，并由荣耀安全组件保护相关传输。清除数据、卸载、设备故障或更换设备可能使本地进度无法恢复。

如发生个人信息安全事件，我们会依法采取补救措施，并依事件影响和法律要求通知相关用户及有关部门。

五、访问、更正、删除与撤回

您可在登录页的法律与本地数据入口、主菜单底部或游戏设置中的“隐私与协议 · 本地数据”阅读完整政策与协议，依法访问、更正、删除信息、撤回同意或要求解释规则。

  • 游戏昵称：在“本机昵称”中编辑昵称或选择“使用默认昵称”；也可在登录页删除本机昵称，之后采用默认角色名。新的角色名称会在相应角色上报时传给荣耀。此操作不修改或注销您的荣耀账号昵称。
  • 删除本地游戏数据：确认后清除本机关卡、积分、道具、设置及本机昵称，保留同意记录，返回登录入口；下次进入需重新登录荣耀账号。删除无法恢复，不会自动删除荣耀 SDK 缓存、已上报角色记录或荣耀账号。
  • 撤回隐私同意：确认后删除本版同意记录、清除本次应用内登录状态并关闭应用，保留本地进度和昵称；下次启动重新显示同意页，未经重新同意不再次初始化本应用的联运登录服务。撤回不影响此前合法进行的处理，也不等于从荣耀服务撤销授权或删除其历史数据。
  • 系统清除数据：在系统“设置 → 应用 → 毛线绕绕乐 → 存储”中清除应用数据可删除本应用私有区域的全部本机记录，包括其中的 SDK 缓存；不删除荣耀基础服务应用或其服务器的数据。系统菜单名称可能略有不同。
  • 荣耀信息与授权：可前往荣耀游戏中心/账号中心管理账号资料，或按荣耀声明在“游戏服务控制 → 停止游戏服务”等入口停止相应服务。需要删除平台已处理的数据，可联系荣耀或通过下方联系方式由我们协助。删除整个荣耀账号会影响其他荣耀服务，请先阅读平台提示；本应用不冒称已执行荣耀账号注销。
  • 拒绝或停止使用：同意复选框不预选；不同意可退出。账号登录及必要联运服务是本版进入游戏的条件，无法以游客方式绕过。您可停止使用或卸载应用。

您可通过下方联系方式请求访问、复制、更正、删除、限制处理或解释信息规则。涉及荣耀数据时，我们会在核实必要身份信息后协助转交并协调处理；不会要求与请求无关的身份资料。依法无法完全满足时会说明理由。

六、未成年人保护

适龄提示：建议8周岁及以上。这是开发者根据玩法提出的建议，不是官方年龄评级。未成年人应在监护人指导下阅读政策、协议及荣耀 SDK 声明，合理安排游戏时间。

不满14周岁用户应由监护人阅读并同意后使用。实名所需姓名、身份证号等材料通过荣耀流程处理；监护人应帮助孩子避免在游戏昵称或反馈中提供身份信息。荣耀实名、防沉迷与儿童保护规则依账号状态和平台流程执行，可能限制进入或要求结束游戏；应用按相应回调执行。

如我们得知未取得必要监护人同意而处理了儿童个人信息，将依法停止相关处理并协助删除。监护人可通过下方渠道联系我们。
