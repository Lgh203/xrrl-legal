当前版本是本地游戏：您可以使用游客身份，不必填写昵称。昵称、游戏进度、设置和隐私选择保存在您的设备中，不上传至我们的服务器。

当前未接入荣耀账号、广告、支付或统计分析 SDK，没有在线账号、广告展示和付费服务。将来如启用新的服务或 SDK，我们会在启用前更新本政策、说明实际处理的信息，并在依法需要时重新征得您的同意。

一、我们处理哪些信息及其用途

信息或功能用途及处理方式是否必需
可选本地昵称您自行填写的昵称仅用于本机显示和个性化称呼。它不是登录账号，不用于实名认证，不向其他玩家展示或向我们上传。请不要填写真实姓名、身份证号码、手机号等敏感内容。可选。留空或选择游客也可使用游戏。
本地游戏数据关卡进度、游戏内道具及收集状态、音乐音效和振动等设置，在本机保存以便继续游戏。游戏内道具仅服务于本地玩法。用于保存游戏；您可清除本地数据重新开始。
隐私选择及版本记录本机记录您是否同意当前版本政策，以展示入口和避免重复提示；不与设备标识或服务器账户关联。用于落实您作出的选择。
基础运行环境游戏引擎在本机使用屏幕尺寸、操作系统版本等基础运行环境信息，适配画面、声音和触控。不会将这些信息用于识别或跟踪您，也不向我们上传。游戏运行所需的本地适配。
您主动提交的咨询信息若您通过邮件或电话联系我们，我们会使用您主动提供的联系方式、问题描述和必要附件来答复、核实及处理请求。请不要发送与问题无关的个人信息。可选，仅在您联系时处理。

游戏不采集或上传身份证信息、手机号、精确位置、通讯录、照片、录音、已安装应用列表，或 IMEI、Android ID、OAID、MAC 地址等可用于追踪的设备标识。当前没有在线排行榜、聊天、云存档、推送、用户画像或个性化广告。正常游戏不需要您向我们提供个人身份信息。

二、设备权限与本地能力

当前游戏仅使用 Android 的普通振动权限（VIBRATE），在支持的设备上提供游戏触感反馈；该权限不访问个人信息。您可在游戏设置中关闭振动。画面显示、触摸操作和声音播放使用系统的基础能力。

游戏不请求摄像头、麦克风、定位、通讯录、电话、照片或共享存储等敏感权限。存档位于应用私有存储中，不需要您授予访问相册或文件的权限。游戏本体及内置协议可离线使用；您主动通过浏览器访问在线协议或外部网页时，网络请求由相应浏览器和网站处理。

三、第三方组件、共享与在线网页

当前游戏使用 Cocos 游戏引擎在本机运行画面、声音、触控及关卡逻辑，不通过该引擎向我们或广告平台上传用户数据。当前未集成荣耀账号、广告、支付、推送或统计分析 SDK。我们不出售您的个人信息，也不为广告营销向第三方共享您的本地游戏数据。

本政策和用户协议的在线版本托管在 GitHub Pages。您打开在线网页时，浏览器会向网页托管服务发送正常的网络请求，GitHub 可能为提供服务与安全目的处理访问 IP、请求时间及浏览器请求信息。这属于网页访问过程，与游戏的本地存档、昵称和游戏行为分开；我们没有在页面中加入统计脚本、广告、第三方字体或跟踪工具，也没有设置收集信息的表单。

GitHub 的处理规则及可能涉及的境外处理请参阅其隐私声明和GitHub Pages 说明。您可以选择仅阅读游戏内置的离线协议。上述网页访问不会把本地游戏存档或昵称传给 GitHub。

若因法律规定、司法或行政机关依法提出要求，需要处理您曾主动提交的咨询信息，我们会核实依据并仅在必要范围内配合。将来如出现实际委托处理、共享、转让或其他新的处理活动，我们会依法履行告知、保护和必要的同意义务。

四、存储期限与安全

昵称、游戏数据、设置和隐私选择存储在您的设备的应用私有区域，我们没有为这些信息提供后台或云端存储。您可通过游戏删除昵称、游戏存档和设置，撤回隐私同意记录，或通过系统设置清除全部应用数据；未执行相关操作时，这些记录保留在本机以支持继续使用。主动咨询的信息仅在答复、解决问题及履行法定义务所必需的期间保存，目的完成后依法删除或作去标识化处理。

我们通过应用私有存储、关闭应用自动备份、减少权限和减少数据处理等措施保护信息。请保持设备安全、及时安装可信更新，避免向他人提供含个人信息的截图。清除数据或卸载后，本地进度可能无法恢复；更换设备不提供云端迁移。设备系统、浏览器或您自行使用的备份工具的处理依其自身设置与规则执行。

如发现可能影响您个人信息安全的事件，我们会依法采取补救措施，并根据实际影响和法律要求通知受影响的用户及有关部门。

五、访问、更正、删除和撤回同意

您可在游戏右上角的“隐私与协议·本地数据”入口查看本政策与用户协议，并管理本地昵称和游戏数据。您享有依法了解、决定、限制或拒绝信息处理，以及访问、更正、删除信息和请求解释处理规则的权利。

  • 昵称：在入口选择游客，或在菜单的“本机昵称”中编辑昵称、切换为游客；昵称不构成在线账户。您无需提供身份资料，也不必办理网络账号注销。
  • 本地数据：选择菜单中的“删除本地游戏数据”，确认后清除本机关卡进度、积分、道具、设置及昵称，并返回入口；删除无法恢复，隐私同意状态会保留。也可在系统“设置 → 应用 → 毛线绕绕乐 → 存储”中选择清除数据以删除全部应用数据；不同系统的名称可能略有不同。
  • 撤回同意：选择菜单中的“撤回隐私同意”，确认后清除同意记录并关闭游戏，保留本地进度和昵称；下次启动时会重新显示入口，您仍可阅读协议并决定是否同意。撤回不影响此前依据您有效同意已经进行的处理；如需删除存档和昵称，请同时使用“删除本地游戏数据”或系统清除数据。
  • 拒绝或停止：首次提示不会默认勾选同意；您可查看完整政策、选择不同意并退出。游戏不会因您不填可选昵称而限制游客玩法。您也可停止使用或卸载应用。

对您主动提交给我们的咨询信息，可通过下方联系方式提出访问、更正、删除、撤回同意或其他权利请求。为避免误删他人的信息，我们可能请您提供与该请求直接相关的必要核实材料，并依法及时处理、告知结果。我们不会要求与处理请求无关的身份信息；依法无法完全满足请求时会说明理由。

六、未成年人保护

适龄提示：建议8周岁及以上。这是我们根据当前玩法提出的建议，不是官方年龄评级。未成年人应在监护人指导下阅读本政策和用户协议，合理安排游戏时间，注意休息。

不满14周岁用户应由监护人阅读并同意本政策，在监护人允许与指导下使用。本版本不要求填写真实年龄或身份信息，也不将游客昵称视为实名认证。监护人可帮助孩子使用游客模式，避免在昵称、邮件或附件中提供个人信息，并使用设备自身的时间管理功能。

如我们得知在未取得必要监护人同意的情况下处理了不满14周岁未成年人的个人信息，将依法停止相关处理并及时删除。监护人可通过下方渠道联系我们。未来如启用依法需要实名认证或防沉迷的网络游戏服务，我们会在启用前落实相应措施，并更新相关告知；本政策不表示当前已经接入该类 SDK。

七、政策更新

我们可能因功能或法律要求变化更新本政策，并在游戏内及本页面显示新的日期和版本。处理目的、方式或信息种类发生实质变化时，我们会在新处理开始前清楚告知，并在法律要求时重新取得同意。未经必要告知与同意，不会把本地模式直接改为上传昵称、存档或设备标识的服务。
